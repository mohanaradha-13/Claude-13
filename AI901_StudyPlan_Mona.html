🐍 Python Literacy Requirement (NEW in AI-901)
You need to READ and RUN short scripts — not write large programs. Focus on:
  • pip install azure-ai-projects — SDK installation
  • What model is being called in a code snippet
  • Role assignments (system, user, assistant)
  • What a function returns (text, JSON, stream)
from azure.ai.projects import AIProjectClient

client = AIProjectClient(
  endpoint="...",
  credential=DefaultAzureCredential()
)

response = client.agents.run_agent(
  agent_id="my-agent",
  prompt="Summarise this text"
)

Top 10 AI-901 Exam Strategy Tips
1
Domain 2 is king (55–60%) — Spend 60% of your prep time on hands-on Foundry labs. Reading docs is NOT enough for Domain 2. You must actually deploy a model, build an agent, and run Content Understanding.
2
Use the NEW terminology only — Any answer mentioning "Cognitive Services" standalone, "Form Recognizer", or "Azure AI Studio" as separate products is likely a DISTRACTOR. Use: Foundry, Content Understanding, Document Intelligence.
3
Agent = Model + Instructions + Tools — For any "what are the components of an agent" question, look for these 3 items. This is the formula. Memorise it cold.
4
Read question stems TWICE — Microsoft writes long scenario stems with constraints near the end ("they want minimal cost", "compliance requires human review"). The constraint often changes the right answer.
5
Score 80%+ on practice tests before exam day — The real exam has time pressure and no reference material. Build a buffer: if you score 75% in practice, you risk failing under exam conditions. Target 80% minimum.
6
Flag and move — Microsoft Fundamentals exams let you flag and revisit. If a question takes more than 90 seconds, flag it, pick your best guess, and move on. Return at the end.
7
Responsible AI scenario matching — Practice mapping scenarios to the correct principle. e.g. "AI loan model approves more men than women" = Fairness. "AI decision cannot be explained" = Transparency. These appear often.
8
Content Understanding ≠ Document Intelligence — They're related but different. Content Understanding is the new Foundry-native tool for extracting from docs, images, audio, AND video. Document Intelligence = legacy/rebranded Form Recognizer.
9
Register with personal Microsoft Account (MSA) — Microsoft explicitly warns: if you register with a work/school AAD account, your exam records will be lost if you leave that organisation. Always use your personal @outlook.com/@hotmail.com.
10
Certification is LIFETIME valid — Unlike Associate/Expert certs that expire in 1 year, this Fundamentals cert NEVER expires. Once you pass, the credential stays on your transcript permanently — forever.
