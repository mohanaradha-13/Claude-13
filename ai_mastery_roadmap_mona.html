Month 1
Programming & Dev Foundations
Go from 40% to genuinely comfortable writing, reading, and debugging Python.
Build
Weekly milestones
  • W1: Python basics — 20 small exercises (use Claude.ai as a Socratic tutor)
  • W2: Functions, files, errors — build a CLI script reading a CSV
  • W3: Git/GitHub — clean repo history; OOP intro
  • W4: APIs/JSON — script that calls a public API and saves results

Mini-project: CLI tool fetching data from a public API, processes it, writes a clean output file. In your GitHub.

Resources: freeCodeCamp Python (YouTube), official Python docs, "Pro Git" (free online)

Month 2
Data & Classical Machine Learning
Functional ML literacy. Enough to use ML correctly and read papers.
Build
Weekly milestones
  • W5: NumPy + Pandas (manipulate a real dataset)
  • W6: EDA + visualization on a Kaggle dataset
  • W7: First supervised models (regression + classification) with sklearn
  • W8: End-to-end ML project: data → clean → model → evaluate → write-up

Key tip: Don't rabbit-hole on math. Learn just-in-time using 3Blue1Brown and StatQuest.

Project: Documented notebook predicting something from a real dataset, honest evaluation. On GitHub.

Month 3
Deep Learning & How LLMs Work
Working understanding — enough to use and reason about deep models.
Working
Weekly milestones
  • W9: NN fundamentals + PyTorch basics (build/train a tiny network)
  • W10: CNN — train an image classifier on a standard dataset
  • W11: Transformers + attention — watch it explained, read "The Illustrated Transformer"
  • W12: Embeddings — generate and visualize; understand semantic similarity (bridges into RAG)

Resources: 3Blue1Brown neural net series, Andrej Karpathy "Zero to Hero" (YouTube), "The Illustrated Transformer" (Jay Alammar), fast.ai

Interview note: Be able to explain attention, embeddings, and what "fine-tuning vs prompting vs RAG" means.

★ Core
Month 4
GenAI / LLM Engineering + RAG
This is your specialization. Deep, hands-on, portfolio-generating.
Build
Weekly milestones
  • W13: LLM fundamentals + advanced prompting (build a prompt library with evals)
  • W14: Embeddings + Chroma (build semantic search over your own documents)
  • W15: Build a RAG pipeline — PDF chatbot over a set of papers in your field
  • W16: Polish + add a simple UI (Streamlit/Gradio — preview of Month 6)

Portfolio pick 1–2: PDF/Research-paper Chatbot (RAG), Document Search System, or Resume Analyzer.

Resources: Anthropic Academy, Hugging Face free course, LlamaIndex docs, DeepLearning.AI "Building RAG"

★ Core
Month 5
AI Agents & Automation
Build agentic systems — the frontier of both industry and research in 2026.
Build
Weekly milestones
  • W17: Agent fundamentals + MCP concept (connect an agent to one external tool)
  • W18: Build a single-purpose agent (e.g., research-retrieval agent) in CrewAI
  • W19: Multi-agent version (retrieve → critique → summarize)
  • W20: Add a tool integration + basic guardrails (human-in-the-loop)

Research tie-in: The "academic literature synthesis" multi-agent pattern is a real, current use case — and a PhD productivity tool. Build that.

Resources: Anthropic Academy (Claude Code, Subagents, MCP), CrewAI docs, DeepLearning.AI agent short courses

Month 6
Deployment, Capstone & Portfolio
Ship something real and presentable. Convert "I learned things" into "here's proof."
Ship
Weekly milestones
  • W21–22: Capstone — RAG Knowledge Assistant for research (Month 4 RAG + Month 5 agent + deployment)
  • W23: Portfolio write-up — clean GitHub READMEs, demo video, one-page project summaries
  • W24: Consolidation — review weakest areas, write your forward-maintenance plan

Tools: Streamlit/Gradio (UI), FastAPI (backend), Docker (containerize one project), Hugging Face Spaces or Streamlit Cloud (deploy)

★ Months 4–5 are the center of gravity for 2026 employability and AI research. Don't skip Months 1–2 — they make 4–5 possible.

What you build

Portfolio outcomes

Retrieve → critique → summarize pipeline. The "academic literature synthesis" pattern — a real agentic use case.
Deployed public app
At least one project live on Hugging Face Spaces or Streamlit Cloud — something anyone can actually use.
2–3 polished portfolio projects
Clean GitHub READMEs, demo videos, and one-page write-ups. Teaching demos for a future professor portfolio.
A final realism note

This roadmap is honest about being a foundation, not a finish line. Six months at 1–2 hrs/day makes you genuinely capable at the applied GenAI/agent layer — the hottest layer in 2026 and most relevant to AI research. Depth in Months 4–5 beats shallow coverage of all six. Resist the urge to "complete everything"; aim to build things you understand.
