# Claude-13
🚀 I just built my first virtual creation — and I made it entirely with Claude.

It's called The Training Run: a complete 12-month roadmap that takes someone with only basic Python all the way to AI/ML Engineer and Generative-AI builder — with no tutor, no bootcamp, and only free resources.

The idea behind it: in machine learning, a model starts knowing nothing and, over many training "epochs," slowly converges into something capable. So I built the whole roadmap around that metaphor — you are the model, and 12 months is your training run. Each month is one epoch, and the landing page even has a loss curve that drops as your skill rises.

What's inside:
📅 12 monthly epochs → 4 weeks each → a simple daily rhythm (2 hrs on weekdays + 4 hrs on weekend days = 18 hrs/week)
🧠 Beginner → Intermediate → Advanced → Expert, ending in a solo capstone month
🛠️ Python, math intuition, Git/GitHub, classical ML, deep learning, computer vision, NLP, Transformers & Hugging Face, LLMs, prompt engineering, RAG & AI agents, and deployment
🔗 Real, hand-checked free resources under every epoch — Andrew Ng, fast.ai, Hugging Face, 3Blue1Brown, Andrej Karpathy, Kaggle, and Anthropic's own courses
💼 11+ portfolio projects shipped to GitHub along the way

How I made it: I worked with Claude (Anthropic) end to end — to shape the concept, design the full curriculum, write every line of copy, and code the landing page itself (a single responsive web page with an animated loss-curve visualization). What used to take a team, I prototyped solo, in hours.

As an educator heading toward a PhD in AI, this was my proof to myself that the tools to learn — and to build — have never been more within reach. The barrier isn't access anymore. It's just starting.

If you have a laptop, Wi-Fi, and 18 focused hours a week, you can run this. 🌱
